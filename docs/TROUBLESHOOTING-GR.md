# Βοήθεια για το εργαστήριο

| Τι βλέπω | Τι κάνω |
|---|---|
| `Open .env ...` | Ανοίγω το `.env`, βάζω το προσωπικό key μετά το `=` και αποθηκεύω. Δεν στέλνω το key σε κανέναν. |
| `Open student-config.txt ...` | Βάζω το ακριβές Minecraft username μου. Το αρχικό `YourPlayerName` είναι μόνο υπόδειγμα. |
| `Minecraft server is unavailable` | Ο εκπαιδευτής ξεκινά τον server. Ελέγχω τη διεύθυνση και την έκδοση 1.21.11. |
| `AI unavailable` ή HTTP 503 | Η AI δεν απάντησε σωστά. Το bot σταματά με ασφάλεια. Περιμένω και δοκιμάζω ξανά μία φορά. Αν συνεχίζεται, ενημερώνω τον εκπαιδευτή. |
| HTTP 401 | Ο εκπαιδευτής ελέγχει αν το key/token είναι σωστό, έχει ανακληθεί ή έχει λήξει. Δεν στέλνω screenshot του key. |
| HTTP 402 | Ο υπεύθυνος λογαριασμού ελέγχει credits και όριο χρήσης. Δεν αυξάνω όρια χωρίς συνεννόηση. |
| HTTP 429 | Περιμένω. Μπορεί να έχει συμπληρωθεί το όριο του μαθήματος. |
| `Stay within 64 blocks` | Πλησιάζω στο bot και στο σημείο όπου ξεκίνησε. Επιλέγω πιο κοντινό προορισμό. |
| `cannot find a safe path` | Διαλέγω σημείο με έδαφος και ανοιχτή διαδρομή. Το bot δεν χτίζει γέφυρες και δεν σπάει blocks. |
| Καμία αντίδραση σε δεύτερη εντολή | Περιμένω να τελειώσει η προηγούμενη και τουλάχιστον τέσσερα δευτερόλεπτα. Για άμεσο σταμάτημα: `!stop`. |
| `Disconnected` | Ενημερώνω τον εκπαιδευτή. Όταν λειτουργεί πάλι ο server, ξεκινώ ξανά το START-BOT.bat. |

Οι παρακάτω βλάβες εμφανίστηκαν πραγματικά στην ανάπτυξη:

- **Το Java στο PATH κολλούσε.** Χρησιμοποιήθηκε η υπάρχουσα εγκατάσταση Java 25 με συγκεκριμένο executable, καταγραμμένο μόνο στο ιδιωτικό `.local/runtime.json`. Δεν χρειάζεται ο μαθητής να αλλάξει Java settings.
- **Η εγκατάσταση npm αποκλείστηκε από το sandbox δικτύου του εργαλείου ανάπτυξης.** Η ελεγχόμενη εγκατάσταση με επιτρεπόμενο δίκτυο πέτυχε. Σε σχολικό PC ζητάμε βοήθεια από τον υπεύθυνο· δεν απενεργοποιούμε firewall/antivirus.
- **Το test δεν μπορούσε να συνδεθεί στο δικό του localhost.** Ήταν περιορισμός του sandbox. Δεν ήταν απόδειξη ότι ο Minecraft server είχε βλάβη.
- **Η εντολή δημιουργίας πίστας είπε `That position is not loaded`.** Η πίστα δεν υπήρχε και οι test clients έπεφταν. Ο εκπαιδευτής πρέπει να φορτώσει τα chunks με `forceload`, να περιμένει και να επιβεβαιώσει το `fill`. Οι τελικές δοκιμές ελέγχουν ότι οι παίκτες πατούν στο Y=64.
- **Μία πραγματική δοκιμή AI επέστρεψε σφάλμα μέσω gateway.** Το bot δεν κινήθηκε. Μία επόμενη άμεση OpenRouter κλήση επέλεξε σωστά `follow`. Οι επαναληπτικές δοκιμές και η τελική κατάστασή τους καταγράφονται στο [Test Report](TEST-REPORT.md).

Οι κωδικοί 401/402/429 στον πίνακα είναι οδηγίες αντιμετώπισης, όχι δήλωση ότι όλοι εμφανίστηκαν σε πραγματικό gameplay. Για τους ακριβείς ελέγχους διάβασε το Test Report.

Αν κοινοποιήσεις κατά λάθος το key, ανάκαλέσέ το στο [OpenRouter](https://openrouter.ai/settings/keys) και βάλε νέο στο `.env`. Μην προσπαθήσεις να το «κρύψεις» μόνο διαγράφοντας το μήνυμα.
